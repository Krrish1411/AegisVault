# AegisVault AI Buildbook

This folder is the build-control plane for implementing AegisVault with Gemini/Antigravity or another coding agent.

## Start here

1. Open `PROJECT.md`.
2. Open `PROGRESS.md`.
3. Open `MASTER_AGENT_PROMPT.md`.
4. Open `ARCHITECTURE.md`.
5. Open `SECURITY.md`.
6. Open `UI_UX.md`.
7. Start with `phases/PHASE-00.md`.

## Files

- `PROJECT.md` — product constitution and stack decisions
- `PROGRESS.md` — durable AI memory/checkpoint
- `ARCHITECTURE.md` — code architecture and interfaces
- `SECURITY.md` — cryptographic/security rules and threat model
- `UI_UX.md` — premium UI/UX system and screen behavior
- `DATA_MODEL.md` — entities and vault format design
- `DEVELOPMENT_RULES.md` — rules for AI coding behavior
- `TESTING.md` — testing and release gates
- `PHASES.md` — roadmap
- `MASTER_AGENT_PROMPT.md` — prompt to paste/use as the standing agent instruction
- `phases/` — one detailed prompt per implementation phase

## Important

The original product requirements remain the source material for feature scope. This buildbook adds implementation boundaries, UI direction, architecture, AI workflow, and progress management so a coding model can execute the project incrementally instead of improvising.
